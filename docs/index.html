nju-connect在终端或菜单栏里，连上南大校园网

nju-connect 是南京大学校园 VPN 的原生客户端。一个命令行程序负责登录和连接，同时支持 EasyConnect 与 aTrust 两种网关；macOS 上还有一个菜单栏应用，点一下就能连上或断开。

命令行 · nju-connect

一条命令完成登录和连接

命令行是 nju-connect 的核心，菜单栏应用也是调用它完成工作的。连接成功后，它在本机开一个 SOCKS5 代理（默认 127.0.0.1:1081），需要访问校内资源的程序走这个代理即可。

nju-connect setup

在终端里运行会进入引导式设置：依次选择后端和网关，自动发现 aTrust 支持的登录方式，再填写账号和密码。再次运行时，已保存的值就是默认值，只改你回答或用参数指定的项。

# 脚本里用管道传入密码
nju-connect setup --backend atrust --password-stdin
nju-connect connect

同时支持 EasyConnect 和 aTrust。网关要求短信验证码时，会在终端里提示输入。aTrust 会保存登录会话，下次连接直接复用，不用重新登录。密码被拒时会让你重新输入并保存，最多尝试三次。

# 不带命令等同于 connect
nju-connect
Verification code: ••••••
nju-connect status --json

查询正在运行的连接，输出带版本号的 JSON，方便脚本和其他工具读取。加上 --watch 每秒输出一行最新状态。没有连接时退出码为 1。

{"schema_version":1,"running":true,
 "state":"connected","profile":"atrust-tcp",
 "socks_listen":"127.0.0.1:1081", …}
nju-connect speedtest

测量到南大测速站 speed.nju.edu.cn 的下载、上传和延迟。优先走直连；不在校内时，自动改走正在运行的 nju-connect 代理，结果里会注明走的是哪条线路。

status: success
route: direct
target: speed.nju.edu.cn
download_mbps: …
密码存进系统钥匙串

VPN 密码和 aTrust 会话保存在系统的凭据存储里：macOS 的登录钥匙串、Linux 的 Secret Service、Windows 凭据管理器。配置文件里只有账号和网关这类非敏感信息。没有钥匙串的服务器（比如通过 SSH 登录的 Linux）可以改用仅本人可读的文件。

# config.toml
credential_store = "file"
macOS · Linux · Windows

纯 Go 实现，不依赖 cgo，可以为 Linux、macOS、Windows 的 amd64 和 arm64 构建。nju-connect doctor 会检查本机配置，并告诉你下一步该运行哪条命令。

nju-connect doctor
ready: true
next: nju-connect connect

macOS 菜单栏应用

在菜单栏里点一下就能连上

  • 一键连接和断开

    在面板顶部选择 Off、EasyConnect 或 aTrust，就能开关连接或切换后端。第一次使用时，在面板里填入南大账号和密码，点「Save & Connect」即可。需要验证码时，面板里会出现输入框。

  • 实时状态和流量

    打开面板时，实时显示连接状态、最近 30 秒的上传与下载速率曲线、本次会话的累计流量和活跃连接数。菜单栏图标本身也会反映连接状态。

  • 校园测速

    面板里可以直接对 speed.nju.edu.cn 测速，显示延迟和带宽，并标出走的是校园网直连还是 VPN。展开详情可以看到最近几次的延迟和带宽曲线。

应用的所有操作都通过内置的 nju-connect 命令行完成，密码经由命令行存入钥匙串，验证码通过私有的本地管道传递，不会被保存。需要 macOS 13 Ventura 或更高版本。

安装

通过 Homebrew 安装，或从源码构建

macOS 上的 Homebrew 安装包同时包含菜单栏应用和 nju-connect 命令。Linux 和 Windows 目前需要从源码构建。

  1. 从 soundadam/tap 安装

    brew install --cask soundadam/tap/nju-connect

    会一并安装测速所需的 librespeed-cli-soundconnect，以及终端里的 nju-connect 命令。

  2. 第一次打开前：处理 Gatekeeper 拦截

    这个应用没有经过 Apple 公证。它使用 ad-hoc 签名，作者目前没有 Apple Developer ID。Homebrew 会保留下载文件的隔离属性，安装包也不会替你绕过 Gatekeeper，所以第一次打开时，macOS 会提示无法验证开发者并拒绝运行。

    请先确认你愿意信任这份构建，再选择下面一种方式放行：

    • 打开「系统设置 › 隐私与安全性」，在底部找到 nju-connect 的提示，点「仍要打开」。
    • 或者在终端里移除隔离属性。命令行程序在应用包内，放行应用后 nju-connect 命令也能正常使用。
    xattr -dr com.apple.quarantine /Applications/nju-connect.app

    想先核对再放行？每个版本的 GitHub Release 都附有 SHA-256 校验值，源码也完全公开，你可以自行比对，或者直接从源码构建。

  3. 设置账号并连接

    点击菜单栏里的 nju-connect 图标，在面板里填入账号和密码；或者在终端里运行：

    nju-connect setup
nju-connect connect

  1. 准备 Go 1.25 或更高版本，然后构建

    git clone https://github.com/soundadam/nju-connect
cd nju-connect
go build -o nju-connect ./cmd/nju-connect

    Windows 上把输出文件名改成 nju-connect.exe。要一次交叉编译全部六个平台，运行 make build-platforms。

  2. 设置并连接

    ./nju-connect setup
./nju-connect connect

    在没有 Secret Service 的 Linux 主机上，在 config.toml 里加入 credential_store = "file"。aTrust 的浏览器登录助手只在 macOS 上提供；其他平台使用 OAuth 登录时，命令行会打印登录链接，请把浏览器跳转后的回调地址粘贴回终端。

  3. 测速（可选）

    speedtest 需要一个打过补丁的 librespeed-cli。macOS 的安装包会自动装好；其他平台请自行构建，并用 NJU_CONNECT_LIBRESPEED_CLI 指向它的绝对路径。
